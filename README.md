# NAP community text mining

How do National Adaptation Plans (NAPs) talk about local communities, and does this differ between Annex I and non-Annex I countries?

(Work in progress. Data, method and limitations to be added.)

## Country groups
Countries are grouped by UNFCCC Annex status: Annex I is used as a proxy for the Global North, and non-Annex I as a proxy for the Global South. This is a proxy with known limits: the classification dates from 1992, Annex I includes economies in transition, and some wealthy countries are non-Annex I.
